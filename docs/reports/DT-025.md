# DT-025 — Exact topology and Strand cross-floor restoration

Date: 2026-09-23. Status: implemented, verified and deployed locally as a
candidate-backed loopback demo.

## Root cause and correction

The endpoint-only graph preserved all six recorded Strand Hall stair transitions
but split 313 Strand rooms across 122 default-profile components. It failed to node
source-authored cases where a pathway endpoint equals an interior vertex of another
pathway at the same exact XYZ and level. `SH1036` therefore exposed seven same-floor
destinations and `SH1036` → `SH3050.1` returned HTTP 409.

The immutable source directly confirms those shared vertices. The existing
`exact-shared-vertices-v1` builder splits only those authored single-part source
lines, preserves source spans and authoritative length, and rejects ambiguous snap
cells. No proximity join, inferred intersection, gap edge or room connector was
added. ADR-0018 makes this mode the default for new builds; explicit endpoint mode
and endpoint fallback for legacy manifests remain tested.
