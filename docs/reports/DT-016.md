## What is now runnable

- `source_review.py` compares all seven indoor layers and inventories supplemental
  metadata. Its deterministic report includes source directory identities, schema/CRS
  comparisons, per-FID attribute/WKB fingerprints and actionable diagnostics.
- `rebuild.py` preserves raw extraction, normalizes a separate copy, builds all graph
  stages, records a hash-verified stage chain, and rechecks source identity before
  completion. Exclusive run directories, symlink refusal, stage/input validation and
  code/image checks protect isolation and prevent accidental reuse or stale completion.
- `build_semantics.py` compares complete graph structure/attributes, routing-unit
  inputs, approximate anchors and profile-specific room-pair reachability. It validates
  matching reverse arcs before treating component groups as exact directed reachability.
- PowerShell/POSIX launchers pin execution to the Docker-inspected immutable image ID.
  `make etl` now invokes the complete isolated pipeline with an explicit run ID.
