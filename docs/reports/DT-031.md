## Result and boundary

Capture navigation and room ownership at the original destination click, before
availability is awaited. Keep waiting-click revisions separate from submitted-route
generations: newer waiting clicks supersede older waiting clicks, while a rejected
choice cannot discard a valid request already in flight. Clear and other route
submissions invalidate waiting clicks. A valid late result remains available with
Return to route while newer floor exploration remains visible. Obsolete destination
room inspection cannot claim a newer floor or same-floor room inspection.

Route requests retain ownership through their own cancellation of a pending route
scene. Known unsupported destinations are rejected without invalidating a pending
valid route. The interim automatic A/B flow remains; endpoint drafts and the rest
of DT-024 C/D, DT-017 source reconciliation and publication hardening remain open.

No source, geometry, graph, artifact, API or schema changed. The existing candidate
bind-mounts the client, so fresh browser loads receive this client without a demo
restart. No public-stack restart, artifact promotion, push or publication occurred.
