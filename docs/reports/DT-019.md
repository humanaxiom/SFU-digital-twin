how to select an existing local image, or build that image when absent. Inspection
failure is not automatically classified as a missing image: Docker daemon errors
remain visible. Malformed successful inspect output has a separate message.

stage ordering and failure propagation are preserved. No pull or fallback is added.

scope. The plan is `docs/plans/DT-019.md`.
