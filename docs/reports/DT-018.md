## Delivered behavior

- One active floor map and a chronological floor journey; express elevators show
  actual served endpoints, and repeated visits keep their route order.
- Explicit transition departure/arrival controls and landing markers with matching
  numbers. Walking selection paints exact spans blue with a halo, arrow and step
  number. Previous/Next, keyboard controls, floor preview/return and fit controls
  use the same selection state.
- Readable room/floor labels, grouped geometry-based directions, a compact layout
  and visible concise room/door and elevator-only limitations. Technical evidence
  stays in expandable route details; selection does not claim live location.
- Additive `guidance` retains the original shortest path, distances, edge sequence,
  legacy steps/geometries, reachability and artifact provenance. The existing
  canonical route fixture is not regenerated to fit the new implementation.
- Directed spans preserve native coordinate segments. Distances reconcile native
  XYZ lengths within ADR-0012's tolerance. Mismatch removes numeric/turn certainty;
  invalid endpoint alignment or excessive expansion refuses presentation entirely.

No raw source, accepted GeoPackage or graph was rebuilt or promoted. DT-017 remains
the separate multipart construction correction and revised-source reconciliation.

## Test-first and independent review

Backend RED covered the missing guidance contract. Thirty-six final synthetic cases
cover within-edge turns, ordered spans, grouped distance, reversed/express/repeated
floor transitions, zero-edge routes, missing metadata, invalid geometry and expansion
limits. Logs/JUnit live under `build/dt018-gates/backend/`.

Independent review caught missing geometry endpoint alignment validation. Six RED
cases reproduced shifted/reversed geometry and node identity conflicts, then passed
with the directed XY guard. A read-only Docker scan of all 19,884 accepted directed
edges checked 39,768 endpoints: maximum difference 0.007000714834552728m, none above
the documented 0.01m tolerance. No tolerance widening was needed. The reviewer
independently reran the 36 tests and found that defect resolved.

Client RED covered technical floor labels, Clear restoring a stale scene, stale
blue paths during floor loading, selected-marker occlusion, transition numbering,
perpetual Loading on return to an already rendered floor, and inconsistent controls
after Clear. Independent frontend review also caught null-floor cancellation and
failed scene requests retaining the wrong floor controls, and decorative route cues
intercepting room clicks. All three now have passing RED-to-GREEN regressions.
Fourteen executable client behaviors and both Python runner tests passed in Docker.
Earlier focused static/client tests passed 27 tests (2.14s, exit 0) under
`build/dt018-gates/focused/`.

The expanded real browser test first failed on the missing guidance response
(`build/takeover-browser/dt018-red/`). Integration attempts 01/02 exposed test-harness
issues: selectors included SVG paths carrying the same step ID as buttons, and native
button Enter required the full key event. Both were corrected without weakening
coordinate, floor, selection or keyboard assertions. Their failure evidence is retained.
Integration 03 passed before the final lifecycle fixes; it is retained as intermediate
evidence. The final browser run uses fresh containers and includes the frozen fixes.

Visual review then caught fragmented SVG strokes even on the available Strand route.
A Docker Chromium comparison of identical coordinates showed that native EPSG values
and per-path translations lose stroke precision, while a shared scene-local origin
renders continuously (`build/takeover-browser/svg-precision/abc.png`). The fix applies
one origin to all map primitives without changing any native geometry. All halos
paint before selected strokes so adjacent pieces cannot erase each other's blue line.
Client and browser checks reconstruct the native coordinates exactly. The post-fix
Strand walking screenshot was inspected. The earlier `dt018-final` browser run passed
its assertions but predates this rendering correction and is not final acceptance.
