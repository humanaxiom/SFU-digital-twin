candidate and proxy were stopped. Neither 18007 nor old proxy port 8007 matched
the supplied router ranges. The user explicitly confirmed public 8010–8020 maps
to local 18080–18090 on 192.168.1.80.

public TCP 8017 → router target 192.168.1.80:18087 → nginx container 8007 →
private exact-topology demo 8080. Its private host endpoint is
http://127.0.0.1:18107/. `infra/wayfinding-public.env` records deployment settings;
ADR-0020 supersedes the old port assumptions while retaining ADR-0019 controls.
The existing developer stack on 18007 was not recreated or stopped.

Compose/nginx/application code, sources and artifacts were unchanged. The already
verified `sh-navigation-exact-20260923` candidate was restored, with explicit
cached local image use. No ETL, new source-to-candidate build, promotion, Windows
firewall/router modification, push or code publication occurred.
