## Operator behavior

The fixed-output Python module and five individual Make targets now fail with the
supported isolated rebuild command. The source-capable extractor writes all
layers into a temporary directory on the destination filesystem. Successful
explicit overwrite uses atomic replacement. Default extraction installs a hard
link that fails if another process claimed the path first. Exiting the temporary
directory cleans up the staged files on ordinary errors. The public rebuild
launcher creates an unused run directory and keeps all stages and their lineage.
