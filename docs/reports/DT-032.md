# DT-032 — Facilities evidence in room details

Delivery date: 2026-11-19 (America/Whitehorse). Status: final gates passed.

## Scope

The room inspector now displays the recorded room ID, category and use type.
It identifies physical accessibility as unverified. The old inspector displayed
the artifact's Boolean and source metadata date as destination and verification
facts. Existing API clients still receive these legacy fields. ADR-0023 documents
their meaning. Facilities' six answers and remaining export questions are in
[system design §12](../02-system-design.md#12-open-questions-for-stakeholders).
The [plan](../plans/DT-032.md) separates this display change from future ETL,
geometry, search and operational data decisions.
