# DT-026 — Public port 8007 reverse proxy

Status: implemented and verified on 2026-09-23. Architecture and evidence:
[ADR-0019](../adr/0019-public-demo-reverse-proxy.md).
[Delivery report](../reports/DT-026.md).

## Goal

Keep the verified candidate available at `http://127.0.0.1:18007/` and add
`http://sfuai.ca:8007/` for external access to the same mounted client and exact
artifacts.

## Delivery

1. Keep the demo container published only on loopback port 18007.
2. Add a digest-pinned, read-only nginx service in the candidate Compose project.
3. Publish only nginx on `0.0.0.0:8007`; accept `Host: sfuai.ca` and forward a
   fixed `Host: demo` to the existing backend allowlist.
4. Keep logs bounded and omit query strings, bodies, headers and room selections.
5. Record plain-HTTP/no-auth scope, rollback, DNS/NAT/firewall dependencies and
   artifact identity parity.
6. Verify loopback, host-published 8007, invalid Host rejection, AQ and SH
   cross-floor browser routes, full Docker gates, and an outside-network request.

## Acceptance

- `127.0.0.1:18007` remains healthy and unchanged.
- `sfuai.ca:8007` serves the same artifact and graph hashes when reached with
  `Host: sfuai.ca`.
- Arbitrary Host values do not reach the application.
- AQ2035.2 to AQ5046 and SH1036 to SH3050.1 pass through port 8007 in Chromium.
- Rollback removes the external proxy without changing artifacts or the internal
  endpoint.
