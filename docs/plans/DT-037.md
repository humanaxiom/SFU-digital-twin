## Established evidence and fix scope

Exact fresh `/` and `/index.html` AQ3000 → AQ3024.1 → AQ6000 completed in
318/279 ms at baseline. Holding a real scene response body reproduced indefinite
Loading with hidden Retry after 12.6 s; repeat floor activation reused the same
pending request. This proves a client recovery hole, not the original user's
transport cause. In-flight scene caching entered Git in `628c3c2`; DT-036 changed
server construction/caching and left the client switch path unchanged.

The isolated fix bounds scene fetch AND body completion to 10 s using a local
AbortController and Promise.race. Rejection clears the dedup entry and exposes
the existing Retry while preserving prior floor, camera/endpoints and route.
Late responses cannot populate the timed-out promise's cache or override newer
navigation. Normal cache reuse and geometry are unchanged. This is network/body
recovery, not a promise to interrupt synchronous rendering or a suspended tab.
Fresh browser recovery E2E has passed; full checks and final live acceptance
were completed before recording delivery. Existing test assertions remain intact;
VM harnesses receive standard browser timers/AbortController rather than a
production compatibility workaround for incomplete test environments.

The full Docker suite passed 695 tests with 16 documented skips and 87.37%
coverage. Lint, types, artifact QA and launchers passed. Existing full two-click,
Preview and accepted canonical E2Es passed. Integrated HTTP-served client hash
matches the tested snapshot, with no backend restart. Live ordinary exact-flow
replays passed at both `/` and `/index.html`; the user's original pending
transport/browser cause remains unknown and no user reply was treated as proof.
