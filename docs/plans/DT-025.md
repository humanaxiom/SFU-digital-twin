# DT-025 — Restore authored cross-floor connectivity

Status: implemented, verified and deployed locally, 2026-09-23. Architecture:
[ADR-0018](../adr/0018-exact-source-topology-default.md).
Evidence: [DT-025 report](../reports/DT-025.md).

## Problem

The deployed endpoint-only graph retains vertical transition records but fragments
rooms away from them when an authored pathway endpoint lands on another pathway's
exact interior vertex. `SH1036` therefore offers seven same-floor destinations and
cannot route to `SH3050.1`, matching the reported failure.

## Delivery

1. Preserve the accepted deployment and capture a real browser/API RED for the
   reported Strand pair.
2. Reconstruct a sealed `exact-shared-vertices-v1` candidate from the immutable
   source in the isolated Docker pipeline.
3. Make exact shared vertices the default for new rebuilds while preserving
   endpoint mode for explicit comparisons and legacy manifests.
4. Add a permanent Strand cross-floor browser/API fixture covering both clickable
   and dropdown entry, journey floors and Previous/Next transitions.
5. Run focused tests after each implementation iteration, then full Docker gates,
   source/data QA and fresh candidate E2E.
6. Deploy the verified candidate on the loopback demo and record hashes, container
   identity, commands, results and remaining source limitations.

## Acceptance

- `SH1036` to `SH3050.1` returns a route using only recorded pathway and stair
  geometry and displays SH1000, SH2000 and SH3000 visits.
- Floor buttons, floor picker, room clicks and destination dropdown all work in a
  real browser without showing rooms from unrelated buildings.
- Journey floor selection and Previous/Next keep the selected instruction and map
  floor synchronized.
- No proximity edge, inferred intersection, connector geometry or accessibility
  claim is introduced.
- Full project gates and a final browser/API E2E pass after the final runnable state.

## Known boundary

Strand level 100 has three recorded rooms but no authored pathway attachment from
its stair endpoint. Exact topology cannot safely invent that missing connection.
Strand has stairs only, so Elevator only must continue to reject cross-floor Strand
routes.
