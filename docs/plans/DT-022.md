# DT-022 — Diagnose usable connectivity from AQ6071

Status: implemented and verified as an unpromoted isolated candidate.

Exact source-junction loss is confirmed independently. Implement the opt-in mode
in ADR-0015, build both baseline and candidate from the same frozen code, and test
the isolated candidate. Retain the accepted demo/artifacts while evaluating gains.

The user reports the AQ6000 view is meaningless. Direct live API checks confirm
AQ6071 has one reachable destination, AQ6067, approximately 6.43 m away; 1,015
other catalog endpoints are unreachable. A floor-plan polygon is not routing
connectivity. Determine whether graph construction loses source junctions before
attributing this limitation to missing source data.

Parallel work:

1. Trace AQ6071's accepted graph component back to immutable source features,
   including potential endpoint-to-interior-vertex junctions. Record exact source
   identities, coordinates and level/elevation evidence. Do not infer gap edges.
2. Reproduce stale failure text after a failed route followed by choosing a new
   map origin. Clear the previous pair's message when its route is cleared.
3. Make a small reachable set actionable by naming destinations with explicit
   direction buttons, preserving user choice and the full room catalog. Avoid
   presenting a count alone as proof that navigation is usable.

Agree scope after the source trace. Any graph repair needs its own explicit
topology ADR, source-preserving tests, isolated source-to-candidate build and
candidate-backed E2E. Do not silently promote a graph or reset measured baselines.
Current UI repairs require focused RED tests, final Docker gates and real-browser
AQ6071 selection after a failed request, with no stale message or automatic route.
Test the named destination action and its painted route. Record data limitations
separately from the implementation's pass/fail result.

Outcome: ADR-0015's opt-in `exact-shared-vertices-v1` topology mode restores
source-authored endpoint-to-interior-vertex junctions without proximity joins.
The same-source candidate gains 257,108 default and 230,356 elevator-only room
pairs with zero losses. AQ6071 reaches 696 connected destinations. Independent
source-slice audit and candidate browser/API E2E pass. See `docs/reports/DT-022.md`.
