# DT-033 — Protect accepted artifacts from legacy build commands

The five legacy Make stage commands and fixed-output ETL CLI can write individual
stages into the accepted build directory. Retire these operator entry points with
an actionable diagnostic and a nonzero exit. Keep the isolated launcher and
make etl RUN_ID=<unused-id> as the supported build path. Preserve all accepted
artifacts, source data, route semantics and running services.

Demonstrate RED only against disposable outputs. Verify missing prerequisites,
protection of preexisting bytes, and rejection of a reused run ID. Check internal
rebuild dependencies and update active operator documentation and superseded tests.
Run focused and full Docker gates, source QA, a fresh source-to-candidate build
and candidate verification, plus real browser/API fixtures on the new candidate.
Record hashes, commands, skips and review before closing. DT-017 geometry and
candidate promotion remain separate decisions.

The shared extraction helper also accepts explicit overwrite for a caller-supplied
output. Preserve that supported use by staging the entire GeoPackage on the
destination filesystem. Commit only after all layers and counts succeed. Test
invalid source and injected later-layer failure against an existing sentinel,
successful replacement, and refusal to replace an existing file by default.

Completed and independently reviewed. [Verification report](../reports/DT-033.md).
