# DT-002: ETL Infrastructure and Category Mapping Schema

**Status:** planned  
**Phase:** 1 (Foundation → Production-Ready ETL)  
**Date:** 2026-08-30  
**Estimated Effort:** M (3 days)

## Objective

Set up the containerized ETL execution environment, define the controlled vocabulary for categorizing
Units (rooms), and establish the output table schemas that all subsequent ETL tickets will use.

This is the foundation ticket for Phase 1 ETL: no data processing happens yet, but all the
infrastructure and schemas are in place for DT-003 through DT-010 to build upon.

## Context

- The source File Geodatabase is at `C:\repos\sfudt\claude\dtwin-harness\data\IndoorWayfinding.gdb`
  (read-only, never modified).
- Units layer has a free-text `USE_TYPE` field with 62 distinct values (Office, Corridor, Classroom,
  Washroom variants, etc.) per [docs/generated/gdb-profile.txt](../generated/gdb-profile.txt).
- The system must map these to a controlled vocabulary (`office`, `washroom`, `corridor`,
  `vertical_circulation`, `bookable_space`, etc.) for:
  - Filtering search results (e.g., "show only offices")
  - Routing logic (e.g., "avoid routing through mechanical rooms")
  - UI rendering (icons, colors)
- This mapping is **editable by facilities staff without code changes**, so it lives in a checked-in
  YAML file, not hardcoded.

### Step 4: Write `category_mapping.yaml`

Create `packages/wayfinding/src/wayfinding/etl/category_mapping.yaml`.

**Process:**
1. Copy all 62 USE_TYPE values from [docs/generated/gdb-profile.txt](../generated/gdb-profile.txt)
   lines 612–852 (the features from `OGRFeature(SELECT):0` through `:61`).
2. For each, assign a `category` from the controlled vocabulary.
3. For washroom variants, add `accessible` and `gender` flags.
4. For stairs/elevator shafts, mark `accessible: false` / `true`.

**Example mapping logic:**
- `"Office"` → `category: office`
- `"Corridor"` → `category: corridor`
- `"Corridor with Ramp"` → `category: corridor` (ramp doesn't change category)
- `"Stairs"` → `category: vertical_circulation, accessible: false`
- `"Elevator Shaft"` / `"Elevator Room"` → `category: vertical_circulation, accessible: true`
- `"Classroom"` / `"Lecture Theatre"` → `category: classroom`
- `"Research Laboratory"` / `"Computer Laboratory"` / `"Dry Laboratory"` / `"Teaching Laboratory"` →
  `category: laboratory`
- `"Meeting Room"` / `"Conference Room"` / `"Seminar"` / `"Board Room"` / `"Interview Room"` →
  `category: bookable_space`
- `"Cafeteria"` / `"Commercial Kitchen"` / `"Food Preparation"` / `"Dining"` / `"Food Dry Storage"` /
  `"Food Cold Storage"` / `"Dishwashing Area"` → `category: food_service`
- `"Washroom, single-stall, accessible"` → `category: washroom, accessible: true, gender: neutral`
- `"Washroom, men's, accessible"` → `category: washroom, accessible: true, gender: male`
- `"Washroom, women's, accessible"` → `category: washroom, accessible: true, gender: female`
- `"Washroom, single-stall"` → `category: washroom, accessible: false, gender: neutral`
- `"Washroom, men's"` → `category: washroom, accessible: false, gender: male`
- `"Washroom, women's"` → `category: washroom, accessible: false, gender: female`
- `"Washroom, multi-stall, accessible"` → `category: washroom, accessible: true, gender: unspecified`
- `"Mechanical Room"` / `"Electrical Room"` / `"Janitorial Room"` / `"Boiler Room"` /
  `"Comm.-Rm-Clos/Server Rm"` → `category: infrastructure`
- `"General Storage"` / `"File Storage"` / `"Vault"` / `"Locker Male"` / `"Locker Female"` /
  `"Locker Unindentified"` / `"Plant Maint Storage"` → `category: storage`
- `"Public Lounge"` / `"Staff Lounge/Lunch Room"` / `"Student Lounge/Lunch Room"` / `"Public Study Area"` /
  `"Vending Machine Area"` / `"Mail Room"` / `"Shower Unidentified"` → `category: amenity`
- `"Retail Store"` / `"Place of Worship"` / `"Gallery, Display Room"` → `category: retail`
- `"Workshop"` / `"Loading Dock"` → `category: workshop`
- `"Unfinished Space"` / `"Garbage Room"` → `category: other`
- `"Reception"` / `"Copy/Duplicating Room"` / `"Kitchenette"` / `"Equipment Room"` / `"Resource Lib, Reading Rm"` →

Make a best-effort decision; facilities staff can refine the YAML post-delivery.

### Step 5: Write `schema.py`

Create `packages/wayfinding/src/wayfinding/etl/schema.py`.

**Use Pydantic** for validation and documentation:

```python
"""Output table schemas for the ETL pipeline.

All geometry columns are stored in both native CRS (EPSG:26910) and web CRS (EPSG:4326).
"""

from typing import Optional
from pydantic import BaseModel, Field


CRS_NATIVE = "EPSG:26910"  # NAD83 / UTM zone 10N
CRS_WEB = "EPSG:4326"      # WGS84


class FacilitySchema(BaseModel):
    """Facility (building) schema."""
    facility_id: str = Field(..., description="Original FACILITY_ID from GDB")
    code: str = Field(..., description="Building code (AQ, SH, ECC)")
    name: str = Field(..., description="Full building name")
    geom_26910: str = Field(..., description="WKT geometry in EPSG:26910")
    geom_wgs84: str = Field(..., description="WKT geometry in EPSG:4326")


class LevelSchema(BaseModel):
    """Level (floor) schema."""
    level_id: str = Field(..., description="Original LEVEL_ID from GDB")
    facility_id: str = Field(..., description="Foreign key to facility")
    short_name: str = Field(..., description="Human-readable level name (e.g., '3000', '1000')")
    vertical_order: int = Field(..., description="Campus-wide vertical alignment (-2 to 3)")
    geom_26910: str = Field(..., description="WKT geometry in EPSG:26910")
    geom_wgs84: str = Field(..., description="WKT geometry in EPSG:4326")


class UnitSchema(BaseModel):
    """Unit (room) schema."""
    unit_id: str = Field(..., description="Original UNIT_ID from GDB")
    room_id: str = Field(..., description="Human-readable room ID (e.g., 'AQ1004')")
    level_id: str = Field(..., description="Foreign key to level")
    use_type: str = Field(..., description="Original USE_TYPE from GDB")
    category: str = Field(..., description="Controlled category from category_mapping.yaml")
    accessible: Optional[bool] = Field(None, description="Explicitly accessible destination")
    gender: Optional[str] = Field(None, description="male, female, neutral, unspecified (for washrooms)")
    centroid_26910: str = Field(..., description="WKT point in EPSG:26910")
    geom_26910: str = Field(..., description="WKT geometry in EPSG:26910")
    geom_wgs84: str = Field(..., description="WKT geometry in EPSG:4326")


class LandmarkSchema(BaseModel):
    """Landmark (amenity POI) schema."""
    landmark_id: int = Field(..., description="Synthetic ID (deduplicated)")
    category: str = Field(..., description="water_fountain, vending_machine, etc.")
    level_id: str = Field(..., description="Foreign key to level")
    geom_26910: str = Field(..., description="WKT point in EPSG:26910")
    geom_wgs84: str = Field(..., description="WKT point in EPSG:4326")


class DetailSchema(BaseModel):
    """Detail (wall/glazing/door) schema for basemap rendering."""
    detail_id: int = Field(..., description="Original OBJECTID from GDB")
    use_type: str = Field(..., description="AWA, AGL, ADO, etc.")
    level_id: str = Field(..., description="Foreign key to level")
    geom_26910: str = Field(..., description="WKT geometry in EPSG:26910")
    geom_wgs84: str = Field(..., description="WKT geometry in EPSG:4326")


class PathwaySchema(BaseModel):
    """Pathway (horizontal routing edge) schema."""
    pathway_id: int = Field(..., description="Original OBJECTID from GDB")
    length_3d: float = Field(..., description="3D length in metres", gt=0)
    level_id: str = Field(..., description="Foreign key to level")
    geom_26910: str = Field(..., description="WKT LineString in EPSG:26910")
    geom_wgs84: str = Field(..., description="WKT LineString in EPSG:4326")


class TransitionSchema(BaseModel):
    """Transition (vertical routing edge) schema."""
    transition_id: int = Field(..., description="Original OBJECTID from GDB")
    mode: str = Field(..., description="stairs, elevator")
    length_3d: float = Field(..., description="3D length in metres", gt=0)
    vertical_order_from: int = Field(..., description="Starting vertical_order")
    vertical_order_to: int = Field(..., description="Ending vertical_order")
    geom_26910: str = Field(..., description="WKT LineString in EPSG:26910")
    geom_wgs84: str = Field(..., description="WKT LineString in EPSG:4326")
```

**Gotchas:**
- `geom_26910` and `geom_wgs84` are stored as WKT strings for simplicity. Later phases may switch to
  binary WKB or GeoPackage native geometry, but WKT is easiest for Phase 1.
- Pydantic validation is overkill for a pure-extraction pipeline, but it documents the schema
  clearly and can catch type errors during ETL. If it's too heavy, use dataclasses instead.
